# Workflow recomendado

1. Ler o contexto local do arquivo.
2. Identificar o caminho de execução mais próximo do problema.
3. Fazer a menor alteração possível.
4. Validar com erro de compilação, execução ou teste quando existir.
5. Não fazer Git sem pedido explícito.

## Boas práticas

- Preferir correções no ponto de origem do problema.
- Evitar duplicar lógica entre banco simples e robusto.
- Quando houver divergência de schema, usar condição clara no PHP.
- Manter a interface consistente com o restante do projeto.
