# Agents

Esta pasta organiza a base de instruções usada pelos agentes no projeto.

## Ordem sugerida de leitura

1. `AGENTS.md`
2. `agents/overview.md`
3. `agents/git-policy.md`
4. `agents/copilot-context.md`
5. `agents/workflow.md`

Separar contexto geral, política de Git, contexto do Copilot e workflow para ficar mais fácil de manter e reutilizar por diferentes agentes.
