# Base de contexto para o Copilot

Use este resumo para orientar o Copilot com foco no repositório atual.

## Preferências de trabalho

- Priorizar leitura do arquivo atual e dos arquivos próximos antes de editar.
- Fazer mudanças pequenas e localizadas.
- Validar depois de editar quando houver comando disponível.
- Evitar mudanças de estilo fora do escopo.

## Regras importantes do projeto

- O cadastro cria usuários com status `pendente`.
- O login bloqueia contas pendentes ou negadas.
- A área admin aprova ou recusa novos usuários.
- O projeto precisa funcionar nos modos `simples` e `robusto`.

## Observações sobre documentação

- A base oficial para agentes está em `AGENTS.md`.
- As regras detalhadas estão em `agents/`.
- Os arquivos em `.vscode/` servem como compatibilidade com o editor.
