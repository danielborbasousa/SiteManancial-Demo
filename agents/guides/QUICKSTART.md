# 🚀 Quick Start - Checklist Rápido

## Antes de Começar Qualquer Tarefa

### ⚡ 30 segundos

- [ ] Leio a tarefa do usuário
- [ ] Entendo se é feature, bug fix ou melhoria
- [ ] Verifico se preciso do arquivo agents/guides/RULES.md

### 📋 Tarefa Comum

1. **Implementar feature**: Ler docs/ → Código → Testar → Informar
2. **Corrigir bug**: Localizar → Debugar → Corrigir → Testar → Informar
3. **Melhorar UI**: Analisar → Redesenhar → Testar temas → Informar

## ⛔ PRINCIPAIS REGRAS

```
🚫 NUNCA commit/push sem solicitação
✅ SEMPRE aguarde comando explícito
📱 SEMPRE suporte tema claro/escuro
📋 SEMPRE valide dados (cliente + servidor)
🔐 SEMPRE escape strings do banco
```
