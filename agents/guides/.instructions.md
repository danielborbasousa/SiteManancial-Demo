## ✅ Checklist de Features

Ao implementar uma feature:

1. **Análise**
   - [ ] Ler requisitos no docs/
   - [ ] Verificar banco de dados relacionado
   - [ ] Entender fluxo de segurança

2. **Implementação**
   - [ ] Código limpo e comentado
   - [ ] Validação cliente + servidor
   - [ ] Escape de dados do banco
   - [ ] Verificação de sessão

3. **UI/UX**
   - [ ] Responsivo em todos os breakpoints
   - [ ] Tema claro/escuro
   - [ ] Animações suaves
   - [ ] Feedback de erro/sucesso

4. **Testes**
   - [ ] Testar em navegador (Chrome, Firefox)
   - [ ] Testar em mobile
   - [ ] Validar formulários
   - [ ] Verificar links

5. **Git**
   - [ ] Aguardar solicitação explícita
   - [ ] Informar status: "✅ Concluído"
   - [ ] Listar arquivos modificados
