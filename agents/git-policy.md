# Política de Git

## Regra obrigatória

- Não executar `git add`, `git commit`, `git push` ou `git branch` sem solicitação explícita do usuário.
- Não presumir que "finalizar" significa fazer commit.
- Não usar Git em segundo plano por conta própria.

## Quando pode agir

Somente quando o usuário pedir claramente algo como:

- "faça commit"
- "faça push"
- "adicione os arquivos e commite"

## Resposta padrão após alterações

Informe apenas:

- o que foi alterado
- quais arquivos mudaram
- que está pronto para commit quando solicitado
